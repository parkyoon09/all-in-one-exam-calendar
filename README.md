# 올인원 시험캘린더

수행평가·시험 일정을 한곳에 모으고, "오늘 뭐부터 할지"를 우선순위대로 추천해 주는 웹 앱입니다.
설치·서버 없이 파일(`index.html`, `style.css`, `app.js`, `config.js`)로 동작하고, 데이터는 사용하는 기기의 브라우저(`localStorage`)에만 저장됩니다.

## 실행 방법

1. 이 폴더를 통째로 받습니다. (모든 파일이 같은 폴더에 있어야 합니다.)
2. `index.html`을 브라우저(크롬·엣지·사파리)로 엽니다. 끝.

폰에서 쓰려면 폴더를 그대로 정적 호스팅(GitHub Pages, Netlify 등)에 올리고 주소로 접속하면 됩니다.
처음 열면 **빠른 추가**로 일정을 넣거나, **예시 데이터로 둘러보기**를 눌러 바로 살펴볼 수 있습니다.

## 키 넣는 법

키가 없어도 앱은 동작합니다. 키가 없거나 호출에 실패하면 규칙 기반 계산(마감 임박도·반영 비율·남은 할 일)으로 자동 전환됩니다.

| 키 | 용도 | 발급 | 넣는 곳 |
| --- | --- | --- | --- |
| Gemini API 키 | AI 우선순위 추천 | [aistudio.google.com](https://aistudio.google.com) (무료) | 설정 → AI 추천 → 저장 → **연결 테스트** |
| NEIS 인증키 | 시간표 6교시 이후까지 불러오기 | [open.neis.go.kr](https://open.neis.go.kr) (무료) | 설정 → 학교 · 반 → 저장 |

- NEIS 키가 없으면 NEIS가 요청마다 앞의 5개만 돌려주기 때문에, 앱이 하루씩 따로 받아 **월~금 1~5교시**까지만 채워집니다. 6교시 이후는 시간표 탭의 **시간표 직접 입력**을 쓰거나, `config.js`에 키를 넣어 두면 전부 불러옵니다.
- 키 입력 없이 바로 쓰게 하려면 `config.js`에 키를 적습니다. 설정 탭에서 직접 넣은 키가 있으면 그쪽이 우선입니다.
  **`config.js`를 공개 저장소에 올리면 누구나 키를 볼 수 있습니다.** 올리기 전에 파일 안의 안내대로 키 사용처를 배포 주소로 제한하고, 대회가 끝나면 키를 폐기하세요.
- Gemini 무료 등급은 사용량 제한이 있습니다. 제한에 걸리면 규칙 기반 추천으로 바뀌고 사유가 화면에 표시됩니다.

## 데이터 옮기는 법

1. 원래 기기: 설정 → 데이터 → **내보내기** (`jgcal-날짜.json` 파일이 저장됩니다. API 키는 들어가지 않습니다.)
2. 새 기기: 설정 → 데이터 → **가져오기**에서 그 파일을 선택합니다.

브라우저 기록(사이트 데이터)을 지우면 일정도 함께 지워지니, 중요한 시기에는 가끔 내보내기를 해 두세요.

## 시연 순서 (약 3분)

1. 설정 → **시연용 데이터 넣기**
2. 오늘 탭 → **빠른 추가**로 일정 하나 등록
3. 시험 탭 → 과목에 해야 할 일 추가
4. 오늘 탭 → 추천 목록 확인 (**AI에게 다시 묻기** / **다시 계산**)
5. 시간표 탭 → **NEIS에서 불러오기**

## 사용 기록 (효과 검증용)

설정 → **사용 기록**에서 직접 등록한 일정·시험·할 일 수와 추천 완료율(완료한 추천 ÷ 받은 추천)을 볼 수 있습니다.
**기록 복사**를 누르면 날짜별 표가 클립보드에 복사되어 보고서나 스프레드시트에 붙여 넣을 수 있습니다.
기록은 기기 안에만 저장되고 어디로도 전송되지 않으며, 예시·시연 데이터는 세지 않습니다.
